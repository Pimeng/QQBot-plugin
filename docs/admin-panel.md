# EliaAdminPanel 扩展页

QQBot-Plugin 通过 `elia.support.js` 的 `panelExtensions` 接入 EliaAdminPanel。打开面板的“插件扩展”，选择“QQBot 控制台”，即可查看运行数据并管理 QQ 官方平台的自定义菜单、指令面板。原有账号与连接配置仍在“插件控制”中编辑。

控制台通过「运行概览」「自定义菜单」「指令面板」「群与好友」选项卡切换分类。切换分类会保留已访问分类的未保存草稿，未打开的分类按需加载；当前分类由网址中的 `tab` 参数记录，刷新和前进、后退可恢复。切换其他扩展页面或刷新扩展声明时，仍会提示处理未保存修改。

## 接入与生效

将 QQBot-Plugin 与 EliaAdminPanel 安装在同一个 Yunzai 的 `plugins` 目录，并使用支持通用 `resource` 区块和结构化编辑器的配套 EliaAdminPanel 前后端。扩展的页面、选择条件、表单与操作均由本插件声明，菜单和面板请求由本插件调用已有 QQBot SDK 实例完成。

更新本插件、扩展声明依赖的模块或 EliaAdminPanel 后端后，重启 Yunzai，再刷新浏览器。前端源码开发环境还需在 EliaAdminPanel 目录执行 `pnpm build`；使用发布版时按面板自己的前端更新流程更新构建包。若扩展未出现或提示不支持区块类型，先检查两端是否配套，并重新扫描插件或重启 Yunzai。

远程管理需要对应 QQBot 账号已经连接。账号、AppID、连接方式和沙箱设置的修改按配置表单提示重启生效；菜单和指令面板保存成功后直接提交到 QQ 平台，无需重启 Yunzai。

## 数据来源

运行概览展示已配置账号、在线状态、已知联系人、接收/发送消息数及本地消息缓存数量。账号资料包含机器人标识、AppID、连接方式、运行环境和已申请的 Intents；页面不会回显 AppSecret 或访问令牌。

群与好友数据来自本插件的联系人缓存，包含本插件已接触或查询的记录，不能代表 QQ 平台的完整用户或群列表。表格支持搜索和分页。消息计数为本次账号实例连接以来的本地统计，重连或重启后可能重新计数；本地消息缓存条数表示当前保留的记录数，不是平台历史消息总量。

自定义菜单、指令面板及其关联对象在读取时调用 QQ 官方接口。切换账号或场景后，应重新读取对应资源再编辑；不同机器人的 OpenID 不能混用。

## 自定义菜单

选择机器人账号后读取当前菜单。编辑器支持新增、删除和调整一级菜单顺序，编辑按钮名称、类型和内容，并查看菜单预览。折叠菜单可以新增、删除和排序子项；预览用于检查层级、顺序和内容，实际展示以 QQ 客户端为准。

| 类型 | 点击后的行为 |
| --- | --- |
| `send_message` | 将配置文本填入聊天输入框，用户发送后才成为消息 |
| `link` | 打开配置的 HTTPS 链接 |
| `switch` | 切换开关状态；开启后，用户消息的 `ext` 中携带对应 `switch_id=1` 标识 |
| `menu` | 展开子菜单，子项支持发送消息或链接 |

自定义菜单只作用于 C2C 单聊，并对该机器人的全部单聊用户生效。保存会替换当前完整菜单；删除全部菜单项后保存可提交空菜单。

## 指令面板

选择机器人账号和场景，读取当前面板列表。可以创建面板，编辑既有面板的备注和元素，新增、删除及调整元素顺序，并查看内容预览。指令元素的名称也是点击后填入聊天输入框的文本，例如 `/help`；链接元素展示名称并打开对应地址。元素可配置描述和仅管理员操作选项，具体权限效果由 QQ 对应场景决定。

| 场景 | 标识 | 可选生效范围 |
| --- | --- | --- |
| 单聊 | `c2c` | 全局或指定用户 |
| 群聊 | `group` | 全局或指定群 |
| 文字子频道 | `channel` | 全局 |
| 频道私信 | `dm` | 全局 |

创建时选择生效场景和范围。已有面板的内容修改会替换元素列表与备注，保留关联对象；调整场景或全局/指定范围应创建新面板。对单聊或群聊的指定对象面板，可以读取关联列表，并通过添加、移除操作维护对应 OpenID。每次操作最多提交 20 个 OpenID，详情接口最多返回 1000 条关联记录。

删除面板后，该面板不再对用户或群生效。创建、保存、删除和关联对象变更均在确认后调用 QQ 平台接口。

## 保存与冲突处理

编辑先保留为浏览器中的草稿。提交前会显示操作确认；确认后，EliaAdminPanel 重新读取当前选择的资源并检查读取版本，内容或账号身份发生变化时，应重新读取并合并修改。账号、场景和具体面板均参与资源选择，操作使用面板既有的鉴权、来源检查、审计和插件锁。

这里的版本保护是保存前的 GET 校验。外部程序仍可能在重读后、实际写入前修改 QQ 平台数据；官方文档没有承诺这些接口提供平台原子的比较并交换（CAS）或跨客户端事务。请求去重也只在面板当前进程内生效，不能替代 QQ 平台的幂等能力。

写入遇到超时、连接中断或异常响应时，远端可能已经执行操作。先刷新菜单、面板列表或详情确认实际结果，再决定下一步，尤其应避免重复创建面板。未提交草稿不写入 QQ 平台，也不作为本地配置自动保存。

## 平台限制

以下限制依据 [QQ 官方菜单与指令面板文档](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/menu-panel/)及各接口说明。名称和描述中的中文按 2 个字符计，备注按 Unicode 字符计。

| 配置项 | 限制 |
| --- | --- |
| 一级菜单 | 最多 10 项；名称最多 10 个字符 |
| 二级菜单 | 每个折叠菜单最多 5 项；名称最多 14 个字符；不能继续嵌套 |
| 指令面板 | 每个机器人最多 20 个面板，每个面板最多 20 个元素 |
| 面板元素 | 名称最多 14 个字符，描述最多 30 个字符 |
| 面板备注 | 最多 255 个字符，不向 QQ 用户展示 |
| 链接 | 必须使用有效的 `https://` 地址 |
| 关联对象 | 每次创建、添加或移除最多 20 个对应场景的 OpenID |

| 接口 | 官方频率限制 |
| --- | --- |
| 查询菜单 | 30 QPM |
| 修改菜单 | 5 QPM |
| 查询面板列表、详情 | 30 QPM |
| 创建、修改、删除面板 | 10 QPM |
| 修改面板关联对象 | 60 QPM |

QPM 表示每分钟请求次数。刷新、保存前重读及保存后的结果读取都会产生查询请求；避免短时间反复点击。平台权限、内容检查或频控仍可能拒绝操作，页面显示的错误码可用于查阅官方说明。

## 开发验证

在 QQBot-Plugin 目录执行：

```bash
node --experimental-vm-modules --test tests/panel-validation.test.mjs tests/panel-service.test.mjs
```

校验测试覆盖数量、字符长度、按钮类型、场景和关联对象约束。业务测试使用模拟账号、联系人和 HTTP 请求对象，核对真实 SDK 菜单服务的参数包装、账号隔离、分页及错误脱敏，不需要真实账号、AppSecret 或访问令牌，也不调用真实 QQ 平台读写接口。EliaAdminPanel 的资源区块协议、确认和版本行为由其对应测试验证。

在配套 EliaAdminPanel 目录还可执行独立的浏览器回归：

```bash
node tests/smoke/plugins/resource-extension-smoke.mjs
```

该脚本使用面板约定的 Node.js、pnpm 和测试 Chrome 版本，浏览器按面板流程通过 `pnpm test:panel:install` 安装。测试在随机本地端口挂载真实扩展组件与资源接口，数据保存在内存，覆盖嵌套编辑、排序、预览、确认、版本冲突、慢响应切换、资源增删和页面隐藏后的写入结果。默认截图及环境信息保存在面板目录的 `.elia-admin-panel-build-resource-smoke`，可用 `PANEL_SMOKE_SCREENSHOT_DIR` 指定输出目录。

开发实现位于 `lib/panel/extensions.js`、`lib/panel/service.js` 和 `lib/panel/validation.js`；通用资源区块的协议说明见配套 EliaAdminPanel 的 `docs/PLUGIN_EXTENSIONS.md`。
